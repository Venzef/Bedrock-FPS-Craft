# ADR 0001: 여러 Bedrock 실행 환경 지원

- 상태: 승인
- 날짜: 2026-07-14

## 맥락

프로젝트는 Minecraft Bedrock에서 CS:GO 스타일 게임을 구현하며, Windows 로컬 월드, Bedrock Dedicated Server, Realm에서 모두 동작해야 한다.

## 결정

핵심 게임 규칙과 콘텐츠는 세 환경이 공통으로 지원하는 기능만 사용한다. 특정 환경에서만 가능한 기능은 선택적 향상 기능으로 분리하며, 없어도 매치가 정상적으로 시작되고 끝나야 한다.

배포 단위는 가능한 한 동일한 Behavior Pack과 Resource Pack 조합을 유지한다. 환경별 설정이 필요하면 게임 규칙 코드와 분리된 설정 계층에서 처리한다.

## 결과

- Realm에서도 사용할 수 없는 서버 전용 플러그인이나 외부 프로세스를 핵심 기능에 사용할 수 없다.
- 플랫폼별 고급 기능보다 이식성과 일관된 규칙을 우선한다.
- 지원 여부를 판단할 때 세 환경 중 기능 범위가 가장 좁은 환경을 기준선으로 삼는다.
