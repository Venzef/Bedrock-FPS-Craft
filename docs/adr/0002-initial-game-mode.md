# ADR 0002: 최초 게임 모드는 5대5 폭파전으로 제한

- 상태: 승인
- 날짜: 2026-07-14

## 맥락

CS:GO에는 폭파전, 데스매치 등 여러 게임 모드가 있지만, 최초 버전의 구현 범위를 명확히 제한해야 한다.

## 결정

최초 완성 버전은 테러리스트 5명과 대테러리스트 5명이 겨루는 폭파전만 지원한다. 공격팀은 폭탄 설치 또는 상대 전멸을, 방어팀은 설치 저지, 폭탄 해체 또는 상대 전멸을 통해 라운드 승리를 노린다.

다른 게임 모드는 최초 버전의 범위에서 제외한다.

## 결과

- 팀 편성, 라운드 상태, 폭탄, 구매와 경제, 승패 판정을 폭파전에 맞춰 설계한다.
- 데스매치용 즉시 부활이나 별도 점수 체계는 구현하지 않는다.
- 향후 모드 추가를 막는 불필요한 결합은 피하되, 아직 필요하지 않은 범용 모드 프레임워크는 만들지 않는다.
