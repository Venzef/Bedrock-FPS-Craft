# ADR 0004: MR8과 고정 길이 JSON UI HUD

- 상태: 승인
- 날짜: 2026-07-16
- 참고: ActionBar의 책임은 ADR 0005가 대체한다.

## 결정

- 최대 15라운드, 8점 선승제로 진행한다.
- 7라운드 종료 후 참가 집단의 T/CT 역할을 교대한다.
- 점수·자금은 참가 집단에 유지하고 HUD 슬롯과 역할 점수만 현재 T/CT에 맞게 교환한다.
- Title은 202글자 고정 프로토콜을 전달한다. 당시 ActionBar에 자금과 설치·해체 진행률을 표시하기로 한 결정은 ADR 0005에서 교체했다.
- wire에서는 설치 완료를 `BPLNT`, 해체 성공 후 라운드 종료를 `BDEFS`로 전송하고 RP가 이를 ``, `` 정적 문자로 렌더링한다.

## 결과

점수가 한 자리로 유지되어 기존 슬롯 인덱스를 보존한다. BP와 RP 프로토콜은 테스트와 문서를 포함해 항상 함께 변경한다.
