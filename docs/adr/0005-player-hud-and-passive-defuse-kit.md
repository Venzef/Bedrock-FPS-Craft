# ADR 0005: FCAB 개인 HUD와 패시브 해제 키트

- 상태: 승인
- 날짜: 2026-09-01
- 대체: ADR 0004의 ActionBar 책임

## 결정

- 상단 점수판의 202바이트 Title 프로토콜과 생명주기는 유지한다.
- ActionBar는 일반 메시지를 허용하지 않는 JSON UI 전용 데이터 버스로 사용한다.
- `PlayerHudComposer`가 플레이어당 한 번 `FCABWxxAxxxRxxxIxGxx` 20바이트 프레임을 합성하며, 값 변경 시 즉시 전송하고 20틱 heartbeat를 보낸다.
- weapon HUD와 plant/defuse HUD는 같은 프레임을 독립적으로 파싱해 동시에 렌더링한다.
- 해제 키트는 실제 아이템이 아니라 `PlayerMatchState.hasDefuseKit` 패시브 상태다. CT의 상점 구매 성공 시 켜고, 사망·진영 교대·매치 종료 시 끈다.
- 해제 세션은 시작할 때 키트 상태를 읽어 5초 또는 10초를 확정한다. 취소 후 새 세션은 상태를 다시 읽으며 진행률은 승계하지 않는다.
- 첫 번째 유효 설치 또는 해제 요청이 전역 세션을 독점한다. 성공 확정 프레임 `G20`은 해당 실행자에게 10틱 유지한다.

## 결과

ActionBar를 여러 시스템이 덮어쓰는 경쟁을 없애고 탄약과 목표 진행률을 같은 프레임에 안정적으로 표시한다. 패시브 키트는 아이템 이동·복제·선택 슬롯 문제 없이 저장 상태와 상점 정책으로 관리된다.
