# 용어집

- **참가 집단**: 최초 팀 선택으로 정해지며 매치 동안 점수·자금·연패를 유지하는 플레이어 집단.
- **역할(T/CT)**: 현재 라운드에서의 공격 또는 방어 역할. 7라운드 종료 후 참가 집단 사이에서 교대한다.
- **라운드 점수**: 참가 집단이 승리한 라운드 수. 현재 역할 기준으로 HUD의 `P/O` 위치에 표시한다.
- **Title HUD**: BP가 전달한 202글자 고정 문자열을 RP JSON UI가 파싱해 표시하는 경기 HUD.
- **ActionBar 데이터 버스**: `FCAB` 20바이트 프레임으로 개인 weapon HUD와 plant/defuse HUD에 상태를 전달하는 전용 채널. 일반 ActionBar 메시지는 표시하지 않는다.
- **플레이어 HUD 합성기**: 무기·탄약·목표 상태를 한 프레임으로 합쳐 플레이어당 한 번만 ActionBar를 갱신하는 단일 소유자.
- **패시브 해제 키트**: 인벤토리 아이템이 아닌 플레이어별 `hasDefuseKit` 상태. 해제 세션 시작 시 5초 또는 10초 duration을 확정한다.
- **HUD 슬롯**: `PLA`, `PLD`, `PLN` 접두사와 16글자 이름 영역으로 구성된 19글자 데이터.
- **폭탄 설치 상태**: wire의 `BPLNT`를 RP가 `` 문자로 렌더링하는 상태.
- **폭탄 해체 완료 상태**: wire의 `BDEFS`를 RP가 `` 문자로 렌더링하는 라운드 종료 상태.
- **경기 핫바 슬롯**: 화면 기준 1~9번과 Script API 기준 0~8번이 대응하는 경기 전용 9칸 장비 영역.
- **고정 경기 아이템**: 주무기, 보조무기, 칼, C4, 상점 열기 아이템처럼 정해진 핫바 슬롯을 사용하는 아이템. 주무기·보조무기와 C4는 버릴 수 있고, 칼과 상점 열기 아이템은 이동·버리기가 잠긴다.
- **예약 전술 슬롯**: grenades, flash, smoke, thermite를 위해 비워 둔 API 슬롯 3~6(화면 4~7번).
